TASK 2 SCALE RUN FAILURE: Out Of Memory (OOM)

The scale run with 3000 bots (and the subsequent retry with 1500 bots) was killed by the kernel's Out Of Memory (OOM) killer.

Each bot allocates a PendingSlot vector of size 1,048,576 slots (each slot is 32 bytes), requiring 32 MB of memory per bot.
- 3000 bots require ~96 GB of virtual/resident memory.
- 1500 bots require ~48 GB of virtual/resident memory.

Since the host machine has only 16 GB of physical RAM, the kernel terminated the bot processes to reclaim memory.
