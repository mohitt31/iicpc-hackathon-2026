## Troubleshooting (Aftab's Antigravity should self-resolve)
| Symptom | Fix |
|---|---|
| VMs boot but <3 nodes join | TLS/URL: ensure server was started with `--tls-san 192.168.122.1`; check a VM console `sudo virsh console iicpc-bench-0` → look for k3s-agent errors; confirm `192.168.122.1:6443` reachable from the VM (`curl -k https://192.168.122.1:6443`) |
| Token empty / join 401 | Token rotated → re-run `sudo cat /var/lib/rancher/k3s/server/node-token` and re-`terraform apply` with the fresh `-var k3s_token=...` |
| Bot pods `Pending` | Bench nodes not labeled → `sudo k3s kubectl label node iicpc-bench-0 node-role.hft/benchmark=true --overwrite` (repeat 0/1/2) |
| `reference-engine` Pending | It needs the untainted host node schedulable — it is by default in k3s; check `kubectl describe pod` for a stray taint |
| Bot `CrashLoopBackOff` | Manifest already has `--no-gate`; check `kubectl logs` for image arch — must be amd64 (it is). Confirm internet egress on VMs to pull from ghcr.io |
| Bot can't resolve `reference-engine` | DaemonSet already sets `dnsPolicy: ClusterFirstWithHostNet`; confirm that line survived the `--bots` edit |
| Engine saturates at high `--bots` | Single engine pod, N→1 fan-in by design → lower `--bots`, commit the clean run |
| `git push` denied on Aftab box | Use `gh auth login` once, or have Aftab paste the contents of `2.3_distributed_run.txt`; Mohit's Antigravity writes the file + commits instead |
